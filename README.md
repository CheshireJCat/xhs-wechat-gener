# 微信聊天记录模拟生成器

基于用户提供的微信截图制作的小红书离线 H5 小工具。无运行时依赖、无联网请求，上传 `wechat-chat-minitool.zip` 即可使用。

## 使用

每次打开或刷新页面时，先展示“使用须知与免责声明”。仅点击“同意并继续使用”后才开放编辑和预览；无关闭、取消、遮罩关闭或 Esc 跳过入口。后台聊天区在同意前不可见、不可聚焦或操作。同意状态仅保留在当前页面内存，不写入本地存储；从浏览器往返缓存返回时重新提示。普通切换后台、选图返回或相册权限弹窗不会重复中断本次使用。

- 点击聊天标题修改名称。
- 点击右下角 `＋` 新增对话，选择左边 / 右边、头像及图片 / 文字 / 时间 / 撤回。
- 头像区提供 20 款本地快捷头像：默认横向滑动，“查看全部 20 款”展开网格；点击头像回填当前侧，可继续裁剪。素材来自 DiceBear，覆盖插画、手绘、像素、动物、植物、风景、星球等风格。
- 头像按左右分别全局共用，提交后同步所有消息。上传头像可拖动、缩放并裁剪成方形；取消弹窗不会修改全局头像。
- 图片支持原图、1:1、3:4、4:3、9:16、16:9 裁剪比例和 1–4 倍缩放。编辑时保留原图及裁剪参数。
- “撤回”分类无需输入内容：左侧显示 `"{当前聊天标题}" 撤回了一条消息`，右侧显示“你撤回了一条消息 重新编辑”。灰色提示居中、不显示头像，蓝灰色“重新编辑”可点击打开编辑弹窗；修改标题会同步更新左侧撤回提示。
- 双击消息进入编辑，手机也支持长按；键盘聚焦消息后按 Enter 编辑。编辑弹窗可以删除消息；底部左侧“在后面新增对话”可在当前记录后插入文字、图片、时间或撤回提示。取消新增会回到原编辑草稿，提交新增不会改动原消息。
- 点击右上角 `···` 生成完整 PNG 长图，再点击“保存到相册”。该保存按钮使用小红书原生 JSBridge，普通浏览器仅显示预览。
- 首次点击“同意并继续使用”后自动打开使用说明。展示记录保存在本地，后续同意不再自动弹出；仍可点击左上角手动打开。
- 使用说明底部的红色“清空对话”按钮立即清空全部消息（包括图片、时间和撤回提示），不提供撤销；聊天标题、左右头像和使用说明展示记录保留。
- 消息、标题、头像存于 IndexedDB；不可用时尝试 localStorage。存储错误会提示，不会静默声称保存成功。小工具缓存不保证永久保留。

## GitHub 与 Pages

仓库：https://github.com/CheshireJCat/xhs-wechat-gener （私有）。

运行 `bash scripts/deploy-pages.sh`，会先检查当前工具，再把 `dist/` 同步到 `gh-pages` 分支根目录。部署使用临时目录，不切换或清理当前工作区。脚本需要 Git、GitHub CLI 和 Node.js；先通过 `gh auth login` 登录。

在仓库 Settings → Pages 选择 Deploy from a branch，分支 `gh-pages`，目录 `/ (root)`。私有个人仓库需要 GitHub Pro 才能启用 Pages。预期网址为 `https://cheshirejcat.github.io/xhs-wechat-gener/`，以 GitHub Pages 部署成功后的地址为准。

个人私有仓库无法设置禁止 fork 的开关；仓库保持私有、未添加协作者，公众无法访问或 fork 仓库。公开仓库无法禁止 fork。Pages 公开后，浏览器收到的 HTML、CSS、JavaScript 与图片仍可被访问者复制。

网站支持编辑与长图预览；“保存到相册”依赖小红书容器，在普通浏览器不可用。

## 本地运行

需要 Node.js 18+，无需安装 npm 依赖：

```sh
node scripts/preview.mjs
```

打开 `http://127.0.0.1:5173`。开发预览服务器会添加 CSP，阻止外部资源、网络连接、内联脚本等，以核对离线要求；最终 HTML 不自建 CSP。

## 校验与打包

```sh
node scripts/check.mjs
node scripts/check-consent.mjs
node scripts/check-insert.mjs
python3 scripts/package.py
```

`dist/index.html` 是唯一入口，ZIP 根目录直接包含它。仅打包 `dist/` 内容，不含开发脚本、源码映射或构建配置。

## 视觉实现

逻辑画布宽度为 472，按设备实际宽度等比显示，聊天内容独立滚动。默认标题为“张三”，默认内容依次为当前时间、右侧“右下角+号新增对话”、左侧“双击消息和时间编辑、删除消息”、左侧“右上角... 生成预览图”。首次初始化记录当前时间，刷新后不会自动更新时间。已移除手机状态栏，聊天标题栏直接置顶；初始示例导出为 1216 × 2499 像素，更多消息自动增加长图高度。编辑预览与 PNG 导出共用 `renderer.js` 的绘制逻辑。

参考图位于 `dist/assets/reference.jpg`，未改动原文件。聊天标题栏的图标、底部栏及头像使用原图切片保留视觉细节，头像可全局替换。默认引导消息和新增消息均按实际内容排版，颜色从参考图取样。旧版未编辑的完整参考示例会自动升级到新的默认内容，用户已新增或修改的聊天记录予以保留。新标题和新文字采用系统中文字体，因此不同操作系统的字形与 emoji 不保证和参考手机逐像素一致；不能据此宣称任意内容跨设备“完美 1:1”。

长列表只挂载可见范围内的消息。导出保留全部内容，在画布超过 800 万像素或 16000 像素高度时降低分辨率，不截断内容；极端长度无法清晰生成时给出明确提示。用户选图上限 25 MB / 4800 万像素，原图压缩到最长边 1600px，消息裁剪结果最长边 960px，头像 256px。
